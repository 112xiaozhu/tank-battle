# 坦克大战（Battle City）

一个使用原生 HTML + Canvas + JavaScript 实现的经典坦克大战游戏，单文件即可运行，无需任何依赖。

## 玩法

- 控制我方坦克，保护基地（老鹰），消灭所有敌方坦克即可过关。
- 基地被击毁，或生命耗尽则游戏结束。
- 关卡会无限递增，敌人数量与强度逐渐提升。

## 操作

| 按键 | 功能 |
| ---- | ---- |
| 方向键 / WASD | 移动 |
| 空格 / J | 射击 |
| Enter | 开始 / 继续 |
| P | 暂停 |
| M | 静音 |

手机上会自动显示触屏按键。

## 道具

- ⭐ 星：强化火力（最多可同时发射 2 发子弹）
- 🛡 护盾：短暂无敌
- 💚 坦克：增加一条命
- 💣 炸弹：消灭屏幕上的所有敌人

## 地形

- 🧱 砖块：可被子弹击毁
- ⬜ 钢墙：不可摧毁
- 🌊 水面：坦克无法通过，但子弹可越过
- 🌲 树林：遮挡视线

## 运行

直接用浏览器打开 `index.html` 即可，或部署到 GitHub Pages：

仓库 Settings → Pages → Source 选择 `main` 分支 → 保存后即可通过 `https://<用户名>.github.io/<仓库名>/` 访问。
